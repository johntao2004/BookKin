# 明代书斋风格：命名与品牌图像

日期：2026-10-23。页面命名已用于产品；`MingShelf` 是本轮推荐的英文品牌及宣传图概念名，网站运行时英文名称仍为 BookKin。

## 页面命名

| 功能与路由 | 原名称 | 新名称 | 依据与含义 |
| --- | --- | --- | --- |
| 普通馆藏 `/library` | 藏书阁 | 藏书楼 | 明代私家藏书楼的语境直接对应个人书库；不用真实书楼的专名作产品名 |
| 文章收藏 `/articles` | 撷文斋 | 文钞馆 | 借明人古文编选中的“文钞”，以“馆”组成现代产品空间名，表示收录、整理文章 |
| 个人阅读记录 `/annotations` 及来源页面 | 札记轩 | 读书录 | 明薛瑄《读书录》是随阅读与思考积累的记录，用于笔记和随笔更贴近功能 |
| 独立加密书库 `/vault` | 秘藏阁 | 秘阁 | 借历代珍藏图籍的意象，缩短名称；并非声称明代私人书库的统一正式称谓 |
| 阅读概览 `/library/overview` | 阁中一览 | 楼中一览 | 与“藏书楼”对应的现代组合名 |
| 知识网络 `/knowledge-graph` | 知识图谱 | 学脉图 | “学问的脉络”对应书籍正文知识点之间的关联，属于现代功能命名 |
| 3D 场景 `/virtual-library` | 虚拟书库 | 书楼漫游 | 将可移动游览的三维书库说清楚，属于现代功能命名 |
| 文章有序收藏 `/article-collections` | 合集 | 选集 | 对应人为编选成集；创建、加入、整理及错误提示同步 |
| 个人长文 | 博文 | 随笔 | 读书感想与长文写作，用常见文类词替代网络年代感较强的称呼 |

保留“书目”“读书札记”“阅文札记”及直接说明功能的按钮文字。管理设置的用户、角色、安全、邮件等功能不做宫廷官署化命名。

本次仅修改显示名称与服务提示。URL、权限代码、角色上限与依赖、功能开关、数据库结构、书籍文件、阅读进度、批注及秘阁安全流程保持原实现。44 个权限定义的 `code/kind/roles/requires` 与修改前逐项比较一致。

## 可核对的历史来源

1. [故宫博物院：天一阁](https://www.dpm.org.cn/lemmas/241810.html)：明范钦的私人藏书处，以“藏书楼”描述其类型。这里只借空间类型，不沿用天一阁品牌或布局。
2. [美国国会图书馆：《唐宋八大家文钞》](https://www.loc.gov/item/2012402552/)：目录著录明茅坤及万历七年自序，为“文钞”的取词依据。“文钞馆”是本产品的组合名。
3. [国家图书馆：国家珍贵古籍名录](https://www.nlc.cn/migrated/pcab.nlc.cn/gjml/gjzggj/201412/U020141217513656781431.pdf)：著录明薛瑄《读书录》及明刻本。
4. [山东大学：《薛瑄著作在中韩两国的传播及影响》](https://tcsc.sdu.edu.cn/PDF/liuchang.pdf)：讨论《读书录》由平日阅读所得札记积累而成。
5. [故宫博物院：秘阁相关研究](https://www.dpm.org.cn/Uploads/pdf/4712/T00013_00.pdf)：秘阁称谓早于明代，制度随时代变化；本轮只取其珍藏意象。
6. [上海博物馆：明清家具与书房](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/RI00000077)：书案、书架、椅凳及文房器具组合构成读写环境。
7. [中国美术学院美术馆：馆藏明清书房文玩](https://caam.caa.edu.cn/info/1044/2355.htm)：引明高濂《遵生八笺》中的书斋陈设，作为宣传图简素书案、古砚及笔洗的参考。

## 英文名建议

| 名称 | 含义与读法 | 适用方向 |
| --- | --- | --- |
| **MingShelf（首推）** | Ming + Shelf，读作 Ming Shelf，两个音节 | 明代关联最直接；Shelf 明确表达藏书功能，搭配 `Your personal library` 后语义直观 |
| JadeShelf | Jade（玉）+ Shelf（书架） | 东方玉色意象，两个常见英文词，适合更温润、跨朝代的国风 |
| MingPages | Ming + Pages（书页） | 阅读与写作感更强，适合未来更强调内容和笔记的品牌 |

这些是命名方向建议，未作商标注册或域名可用性结论。宣传图采用 MingShelf 展示推荐方向，不自动重命名仓库、服务、镜像或已保存的网站名称。

## 图像交付

- App 图标：`apps/web/public/assets/brand/app-icon-1024.png`，1:1、1024 × 1024、PNG、不透明方形源文件。
- 苹果触屏收藏：`apps/web/public/assets/brand/apple-touch-icon.png`，180 × 180。
- 浏览器图标：`apps/web/public/assets/brand/favicon-32.png`，32 × 32。
- 宣传图：本目录 `mingshelf-poster-concept.png`，1024 × 1536、竖版 2:3；使用推荐英文名的品牌概念宣传图。
- 生成提示词：见 [prompts.md](prompts.md)。图案使用内置 ImageGen 生成，仅用 macOS `sips` 导出标准像素尺寸，未改动图案内容。

图标以书页、格窗／书楼屋檐及小朱印为主，墨青、纸白与朱色呼应书斋。宣传图采用简素明式书案、线装书及文房器物，不复刻某幅古画，不使用清宫重金装饰或其他品牌素材。宣传图为产品意象图，不冒充真实软件截图。

[Apple App icons 规范](https://developer.apple.com/design/human-interface-guidelines/app-icons)列出的 iOS、iPadOS、macOS 图标布局母版为 1024 × 1024，系统施加外形遮罩。交付的是方形 PNG 图案母版，未宣称已构建分层 Icon Composer 工程或上架原生 App。
