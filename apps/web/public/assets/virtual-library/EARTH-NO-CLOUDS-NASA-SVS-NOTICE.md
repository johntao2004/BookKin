# NASA Earth texture

`earth-no-clouds-nasa-svs.jpg` is the 2048 × 1024 `earth_noClouds.0330.jpg` equirectangular Earth image published by NASA's Scientific Visualization Studio for visualization ID 3615.

- Source page: https://svs.gsfc.nasa.gov/3615/
- Source image: https://svs.gsfc.nasa.gov/vis/a000000/a003600/a003615/earth_noClouds.0330.jpg
- Credit requested by the source: NASA/Goddard Space Flight Center Scientific Visualization Studio. Blue Marble Next Generation data courtesy of Reto Stockli (NASA/GSFC) and NASA's Earth Observatory.
- SHA-256: `1ed70af0494a92b69a40e12feffd7b47ad4c92b3d70ad0987fee77212b51635c`

The image is packaged locally so the virtual-library scene has no runtime dependency on NASA's website.
