# Fireplace flame texture

`fireplace-flame-v1.png` was generated for BookKin's standalone virtual-library experiment with OpenAI image generation on 2026-08-22.

The texture is a transparent, vertical fire sprite intended for local WebGL use. It contains no third-party branding, text, logs, room imagery, or runtime network dependency.

Current status (2026-09-06): retained legacy asset. The active fireplace uses the procedural ray-marched volume in `fireplaceFire.ts`, not this sprite.
