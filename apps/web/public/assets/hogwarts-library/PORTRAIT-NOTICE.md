# Still life, not a portrait

The entrance canvas is an original geometric still life: a lamp, three books, and an empty frame. It replaces `portrait-scholar-generated-r2.png`, which was redrawn from a supplied reference and is no longer shipped.

No face, crest, character, or film name is painted into the hall. The texture is generated by `scripts/hogwarts-library/build_narrow_hall.mjs`.
