# BookKin阅读字体

本目录包含本地阅读字体；部分也用于界面排版。预设列表以 `src/components/readers/reader-fonts.ts` 为准。

- Noto Sans SC / Noto Serif SC：Google Noto CJK，SIL Open Font License 1.1，许可文本见 `LICENSE-NOTO-CJK.txt`。
- Source Han Sans SC：Adobe Source Han Sans，SIL Open Font License 1.1，许可文本见 `LICENSE-SOURCE-HAN-SANS.txt`。
- Source Han Serif SC：Adobe Source Han Serif，SIL Open Font License 1.1，许可文本见 `LICENSE-SOURCE-HAN-SERIF.txt`。

- 阿里巴巴普惠体 3.0（Alibaba PuHuiTi）：`alibaba-puhuiti-regular.woff2`；许可见 `ALIBABA-PUHUITI-LICENSE.txt`，不适用项目 MIT 或 Noto 的 OFL。

来源：

- https://github.com/notofonts/noto-docs/blob/main/website/use.md
- https://github.com/adobe-fonts/source-han-sans
- https://github.com/adobe-fonts/source-han-serif
