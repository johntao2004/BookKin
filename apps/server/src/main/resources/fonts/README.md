# Cover font

`cover-sans-sc.otf` is a subset (GB2312 characters, Latin, punctuation, kana) of Adobe Source Han Sans SC Regular,
licensed under the SIL Open Font License 1.1 (see `LICENSE-SOURCE-HAN-SANS.txt`). The family was renamed to
"Silvae Cover Sans" because the OFL reserves the name "Source" for unmodified fonts.
It lets the server draw Chinese titles on generated placeholder covers, since the runtime image ships no CJK fonts.
