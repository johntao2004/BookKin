# 可配置密码复杂度

## 功能

入口：`/admin/users#security` → 密码复杂度。仅主人可以保存，管理员只读。

- 最小长度可配置为 8–128；密码上限固定为 200。
- 可分别要求大写字母、小写字母、数字、英文标点或符号。空白不算特殊字符，不能仅用空白。
- 默认保留至少 12 位，其他复杂度要求由主人开启；不追溯阻止已有密码登录。
- 规则独立保存，不覆盖开放注册配置。
- 主人初始化、成员注册、修改密码、邮件重置统一执行 `PasswordPolicyService` 校验。自动生成的临时密码也满足当前规则。
- 改密、初始化、注册和邮件重置页面使用相同规则提示；改密页不再依赖浏览器原生长度气泡。规则加载失败时不允许改密提交，并提供重试。
- Flyway 追加 V12，未修改已有迁移。
