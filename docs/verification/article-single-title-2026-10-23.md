# 文章标题只展示一次

## 修复

问题来源：抓取正文已包含原文标题，文章转阅读器文档时又补入同名标题。

- 正文开头的标题与文章标题一致时，阅读器复用原文标题，目录也只保留一个标题入口。
- 比较忽略格式空白、零宽字符和兼容字形；真实不同的标题及正文后续章节标题保持原样。
- 原本自动补入的节点作为隐藏定位占位保留，原文节点顺序、段落 ID 和 CFI 结构不移动。
- 新抓取和已保存文章均通过同一适配层生效，不修改数据库正文，也不要求重新抓取。

## 验证

- 当前文章文档与阅读页测试重跑共 18 项通过，覆盖原文标题复用、目录去重、节点保留、格式空白，以及缺失标题和后续同名章节的原有行为。
- lint、类型检查和 `pnpm build` 已通过。预览已通过 `pnpm start:preview` 恢复，API 与前端健康检查均可用。
