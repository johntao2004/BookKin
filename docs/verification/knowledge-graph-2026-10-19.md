# 知识图谱页面验证（2026-10-19）

## 功能与数据含义

- 独立登录后路由 `/knowledge-graph`，主导航提供入口。
- 参考用户指定的 Ant Design NetworkGraph 标签示例，采用同一 G6 力导向网络引擎；处理异步布局的 StrictMode/路由卸载生命周期，避免布局完成前销毁画布。
- 节点只来自 EPUB/PDF 正文知识点，包含名称、精确原文引用、章节路径或页码。普通标签、作者、私人笔记不参与生成。
- 名称经 Unicode/大小写/空格规范化后跨书合并；连线只表示同书共现，不表示推断的因果关系。
- 点击画布节点筛选关联书籍，再次点击/清除/重置恢复；知识点列表提供键盘可访问的同等操作。原文证据链接进入阅读器。
- 主人/管理员可逐书提取；成员只能浏览、筛选。后端生成接口执行角色校验与 CSRF；匿名知识 API 实测返回 401。
- 提取是有明确范围的正文采样：每本最多 12 个均匀分布的章节/页面，各取最多 1800 字符，不是全书穷尽分析。无文本扫描 PDF 不执行 OCR。
- AI 提取必须使用设置中的已启用平台。仅接受引用在源段中连续出现、名称出现在引用内且位置对应的结果。模型无有效结果时不生成推测节点。
- 数据由追加的 Flyway V16 存储；源文件指纹变化后不展示过期结果。同书并发生成有任务占用保护；超时任务可重试，失败不覆盖原有有效结果。NAS 读取使用租约、路径策略及前后 SHA-256 核对，不改写原文件。
