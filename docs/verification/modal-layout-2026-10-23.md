# 全局弹窗内距与对齐

## 实现

原先 Ant Modal 容器、全局 header/body/footer 和兼容 Dialog 的内距叠加；确认框另有 Ant 专用规则，普通标题也会继承页面大标题样式。

- 共用单层内距：桌面左右 20px，手机左右 16px，外侧纵向 16px，区块间距 12px，数值均引用既有设计 Token。
- 标题、正文和底部操作区共用边线。关闭按钮固定 44px 点击范围，并为标题预留空间。
- 统一普通弹窗标题的字体与字号，兼容标题内部的 Typography；身份验证标题保留对称居中。
- 普通 Modal 与兼容 Dialog 均限制视口高度，长正文滚动；标题、关闭和底部操作区保持可见。
- 验证弹窗改为 440px 桌面宽度，收紧说明、OTP、表单项和按钮间距。未修改验证协议、验证码提交和密钥处理。
- hook 确认/信息/成功/警告/错误框默认居中，仍允许显式覆盖；保留原有返回对象、取消及确认回调。
- 抽屉标题及页脚采用相同外侧间距；既有编辑、搜索专用布局继续保留。
- 产品规则记录于 `apps/web/AGENTS.md`。未修改设计 Token，也未提交、推送或部署。
