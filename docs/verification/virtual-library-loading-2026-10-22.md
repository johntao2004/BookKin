# 虚拟书库分阶段加载与缓存验收

用户范围：优化首屏建筑、书籍创建和重复访问缓存；保留原有高精度场景、功能、权限及完整真实馆藏。没有更换框架、减少模型面数或更换素材。

## 实现

| 原行为 | 新行为 | 用意 |
| --- | --- | --- |
| 首屏等待 8 个模块，共 29,957,076 字节 | 原三角面重新分组为 20 个模块，首屏先等待 4 个结构模块，共 8,329,680 字节 | 地面、外围结构、主拱顶和回廊支撑先就绪，其余原有细节后台补齐 |
| 126 本书在初始化调用中集中创建 | 规划完整授权快照，按距相机远近分片创建，帧间让出主线程；创建成功后发布完整快照 | 不把渲染进度误作目录数据；取消/失败释放暂存模型并保留旧快照 |
| 所有封面一起下载并作为原尺寸 GPU 纹理 | 附近封面先请求等比 256px 纹理，书架聚焦、靠近或检查书籍时使用原图 | 远处不抢占下载与显存；高清检查保留，私人图片不进入持久缓存 |
| 重复进入重新请求建筑二进制 | Cache Storage 缓存带内容地址的公开建筑文件，每次校验摘要；96MiB 回收预算、32MiB 待写缓冲上限、损坏逐出、存储不可用时回退网络 | 版本变化使用新地址；不缓存目录、封面、用户和阅读 API |
| 生产静态资产缓存策略未区分版本地址 | 仅成功的内容哈希建筑模块、材质及纹理获得 immutable 响应头 | 页面、配置清单、API 和错误响应保持原策略 |
| 每次分块就绪都请求重算完整阴影 | 保留首帧阴影，后台增量合并为一次完整刷新 | 完成后的光影不变，避免分块越多重算越多 |

`REFERENCE_LIBRARY_ASSET_REVISION` 仍为 r42；交付清单 URL 单独增加 `loading-v1`，避免旧清单缓存。书目仍来自当前用户可访问的完整目录，保留修订检查和分页失败时不发布部分快照。未更改后端权限、安全设置、私人阅读数据和禁书区。

## 完整模型一致性

`verify_modules.mjs` 比较源文件和所有新模块的三角面多重集合：每个面包含材质 ID、三个有序顶点的位置/法线/UV 原字节，保留重复面和绕序。结果：

- 三角面数 **1,547,086**，全部保留；材质定义和纹理原字节完全一致。
- 三角面多重集合 SHA-256：`f49fc51f7f2a182299f53a41a2c5c0b9cae82047cb53f9e410db37ab7e6ebe84`。
- 20 个模块全部加载成功后，运行时建筑面数与源文件一致。模型碰撞配置和三维比例未修改。
- 完整证明：`reference-library-exact-preservation.json`、`reference-library-modules.json`。

## 测量方法与限制

比较本机同一浏览器、1280×720 CSS 视口、相同相机与已登录主人账号、126 本真实本地测试藏书。优化前使用独立生产构建快照和 4188 端口；优化后使用生产构建，最终样本使用独立新端口以区分首次与再次访问。没有修改或模拟 API 数据。

“首帧”统一指 `worldBuildStarted` 到首次完成 `renderer.render` 的场景初始化时间；不包含此前的认证、页面 JavaScript 下载或导航。本报告不把它当作互联网慢速网络上的整页冷启动时间。建筑字节数为首帧前已就绪的模块数据，包含缓存命中的字节，并非网络传输总量。全建筑细节时间不包含所有书籍高清图片完成。

原始记录在同名证据目录。`optimized.json` 是初步版本，其中部分样本与完整测试同时运行；曾发现后台阴影重复更新，后续合并刷新后重新测量。最终比较与全部原始记录分开保存，保留中间结果。

## 浏览器流程

已验证真实馆藏搜索、定位到书架、点击抽出书籍、高清检查、阅读链接、EPUB 正文显示及返回虚拟书库。返回后显示 126 本书、r42 模型、碰撞状态 clear。

固定初始视角的 `before.png` / `after.png` 用于对照完整建筑效果；`book-inspection.png` 记录书籍检查。未把 Blender 渲染或 CPU 几何测试视为浏览器验收。当前支持 multi-draw 的实际浏览器已检查；无 multi-draw 的材质合并回退由自动化测试覆盖，未额外取得实体移动设备或其他 GPU 的浏览器证据。

在一轮本地重建恰好覆盖旧 chunk 后，旧测试标签曾记录 ReaderPage 动态导入失效；页面恢复后阅读与返回成功。最终稳定构建另开新标签复测，日志单独记录，不将旧标签历史错误报告为新的运行错误。

## 最终结果

最终固定生产构建快照在 **4191** 端口测量，一次首次访问、两次新标签再次访问；与基线同一机器、浏览器、视口和 126 本书。

| 指标 | 优化前 | 最终版本 |
| --- | --- | --- |
| 首次可操作首帧 | 1.865 秒 | **0.392 秒** |
| 两次再次访问首帧 | 2.083 / 1.858 秒 | **0.412 / 0.309 秒** |
| 三次首帧中位数 | 1.865 秒 | **0.392 秒，减少约 79%** |
| 首屏必需模块 | 8 个，29.96MB | 4 个，8.33MB |
| 首帧已就绪模块数据 | 36.08MB | 8.33MB |
| 全部建筑细节就绪 | 3.692 / 3.376 / 4.265 秒 | 4.292 / 2.763 / 4.177 秒 |
| 阴影重算次数 | 4 / 5 / 6 | 5 / 4 / 4 |

**取舍：** 可操作首帧明显提前，完整细节继续在后台加载；全部建筑细节的中位数约 3.69 → 4.18 秒，未稳定提速，不将首帧改善解释为全量加载都变快。两次热访问分别命中全部 33 个内容地址资源，复用约 54.2MB 建筑、材质和纹理数据。封面未进入这一持久缓存。

初始化同步收尾原来集中花费约 527–659ms；现在初始世界收尾约十余毫秒，书籍分片创建最长连续片段为 26.7–28.8ms。书籍整个异步过程的墙钟耗时仍为约 0.66–1.18 秒，不能将切片时间误报为整批创建时间。

最终开发预览实测 20 个建筑模块、126 本已显示书籍；W 键移动后相机 z 从 15.345 到 14.497，碰撞状态仍为 clear，随后退回并保留可用预览，控制台无 error。

首次缓存存盘已经改为后台写入；慢磁盘写入回归测试验证：即使写入 Promise 未完成，已校验字节也能交给加载器，另一个同源消费者可复用有上限的待写条目。损坏缓存、失效存储、取消和私人资源排除均有测试。

- `pnpm lint && pnpm typecheck && pnpm test && pnpm build` 全部通过：147 个测试文件、**688 项测试**；另有 **5 项 Sites worker 测试**通过。
- 无损模型校验通过，完整几何保留；未改动本任务后端源代码，未运行后端 Maven 检查。
- 稳定最终场景没有控制台 error；保留旧标签在构建切换时的历史 chunk 错误说明。
- 主项目 API 与 Web supervisor 健康。最终预览使用真实开发入口 **http://127.0.0.1:4176/virtual-library**；它的加载时间与生产构建样本分别报告。
- 未提交、推送或部署。临时生产对比服务器在验证后停止，实际预览保留。

原始最终样本：`virtual-library-loading-2026-10-22/final-production.json`；汇总：同目录 `summary.json`。
