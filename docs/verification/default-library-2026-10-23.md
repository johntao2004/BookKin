# 默认书库与移除移动书籍验收（2026-10-23）

## 实现

- 普通书籍沿用部署配置的默认书库；书库设置取消新增目录表单，保留实时状态与重新检查。
- 旧登记预览及登记提交端点返回 403 / LIBRARY_ROOT_REGISTRATION_DISABLED，不访问文件系统或写入目录。

- 不修改已有目录、文件及任务历史；文章与禁书区继续独立存储。
