# 全站按钮文案与图标精简

## 范围与准则

检查了页面、对话框、共享按钮与书卡菜单的操作标签。自解释的文字按钮不再重复配装饰图标；图标按钮的可访问名称、导航方向、阅读器格式工具、加载指示和可见性标识保留。长说明和选择数量留在内容区域，按钮只描述动作。

## 已调整

- 书单：返回全部书单 → 返回书单；编辑资料与可见范围 → 编辑书单；移除列表分区重复的新建入口。
- 阅读笔记：全部阅读笔记书籍 → 返回笔记；加载更多书籍 → 加载更多；导出按钮去除重复图标。
- 文章与阅读记录：预览排版 → 预览；继续校对 → 校对；确认保存 → 保存；保存阅读记录 → 保存记录。
- 上传与文件操作：新建个人书单 → 新建书单；撤销未保存 → 撤销；取消本次上传 → 取消上传；重新在线补全 → 在线补全；AI 查找未匹配 → AI 匹配；保存并完成 → 确认入库；生成安全预览 → 预览。批量操作数量保留在面板中。
- 设置与管理：保存账户资料、保存邮件配置、保存个性化设置 → 保存；创建并生成临时密码 → 创建账户；发送测试邮件 → 发送测试。
- 图谱：分析按钮不再重复选择数量，保留旁边的已选数量；移除与页头重复的空状态分析入口。
- 普通刷新、保存、上传、编辑、新增、导出按钮和书卡菜单去掉装饰图标；保留文字清晰的危险操作、独立图标控件及真正的导航/格式指示。
- 协作规范已更新为全站统一准则，并明确覆盖此前要求给集合上传按钮加图标的旧约束。

## 验证

- `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build` 通过。
- 全量前端测试：140 个文件、595 项通过。NAS 预览、冲突、执行与失败恢复的既有测试保留；危险动作保持明确名称。
- 使用独立 `VITE_DEMO_MODE=true` 预览抽查书单列表、书单编辑、用户管理、创建用户和字体管理。演示数据没有写入真实书库。
- 用户管理页面检查默认桌面及 390px 手机视口，无横向溢出。弹窗仅打开/取消，没有提交用户创建、密码或 NAS 操作。
- 个人资料页的演示邮箱探测受真实接口限制，出现 401，未把它记为真实资料页流程验收；对应组件测试通过。
- 本次未更改后端、接口、权限、文件操作机制；未提交、推送或部署。
