# 文章与禁书区移动端复验

## 验收环境

- 本地预览：http://127.0.0.1:4176/articles，API/Worker 运行于 8080。
- 在选定标签页后应用视口，逐次读取 `innerWidth`、`innerHeight` 和 `documentElement.scrollWidth` 确认实际尺寸；本次实际验证 320×740、390×844、430×932、768×1024。
- 属于浏览器窄屏模拟，未使用实体手机，未验收真实软键盘、设备安全区或系统文件选择器。

## 发现与修复

- 原导入弹窗：文件输入的固有最小宽度撑开 Grid，390px 下输入框右侧超出弹窗；长表单的底部操作需要滚动整个遮罩才能到达。
- 将独立内容 Grid 的列改为 `minmax(0, 1fr)`，约束子控件和文件选择器宽度；工具行允许按容器宽度换行。
- 导入弹窗接入现有共享 `bk-dialog` 滚动规则与 `ActionToolbar`。正文区域内部滚动，标题、关闭与底部操作留在可见范围，所有间距、圆角沿用已有 Token。

## 已验证

- 四种尺寸：导入弹窗均位于视口以内，控件越界数量为 0，确认保存按钮可见；页面无横向溢出。
- 390px：正文输入、内部滚动、预览/继续校对切换正常，切换后保留草稿内容；未保存测试草稿。
- 文章列表、阅读页、个人笔记、手机导航抽屉，以及禁书区首次设置页均已实际查看。

- EPUB 在 390px 完成加密导入、正文渲染、独立书签保存与锁定隐藏；控制台无错误。
- API 复验：普通阅读时间、批注与进度表未出现该测试账号的记录；跨用户密文读取被拒绝。
