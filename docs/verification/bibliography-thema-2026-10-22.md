# 书籍资料与 Thema 流程验收（2026-10-22）

## 完成内容

上传校对、现有书籍编辑、详情、登录目录与公开目录筛选已接通同一份 Thema 1.6 分类数据。书目资料新增作者介绍和目录，保留现有标题、副标题、作者、译者、语言、出版社、日期、ISBN、系列、标签、简介及公开设置。

- 官方主题数据源：[EDItEUR Thema 1.6 在线目录](https://ns.editeur.org/thema/en)。从官方页面获取全部 **3,422 个 A–Y 主题代码、20 个主栏目**，不包含 1–6 限定符。数据、父级关系、来源、版权、抓取时间及原始页面 SHA-256 保存在 `apps/server/src/main/resources/catalog/thema-1.6.json`。官方英文名称保持原文；中文主栏目和常见别名为 BookKin 补充，不声称官方完整中文翻译。
- 同一个 `ThemaSubjectField` 支持层级浏览、中文别名/英文/代码搜索、最多四个具体主题；第一项是主要主题。主栏目用于浏览和筛选，不能当作具体主题保存。未收录、限定符或超过四项均受服务端校验。
- 分类建议只依赖当前书名、简介及标签，点击采纳后仍需保存；不调用 AI、不自动覆盖书籍的人工分类。不匹配时明确提示资料不足。
- 新上传识别 EPUB 声明的 Thema（OPF scheme 或 authority/term）、nav/NCX 目录和已有作者介绍；PDF 读取实际文档书签及相应元数据，无 OCR。Thema 代码不混入新提取的普通标签。
- 原书读取经过现有根路径校验、文件读租约、读取前后指纹校验。支持 EPUB 2 NCX 的外部 DTD 声明，但禁止加载 DTD 和自定义实体。
- 作者介绍、目录和 Thema 保存到正常书目数据，新增 Flyway V24。扫描尊重各字段 MANUAL 边界；在线补全保留手工清空的字段、私有状态、新资料及已选主题。
- 现有书籍可点击“读取原书资料”补入草稿；已有填写值保留，核对后保存。详情对未手工覆盖的空目录可只读展示原书目录，缺失资料显示 `—`。
- 详情显示 Thema 层级路径并链接至藏书库筛选。登录和公开列表均在服务端执行分类前缀筛选、分页、格式与关键词组合；支持“未指定 Thema 分类”。原自定义分类仍可独立使用。
- 现有虚拟书库沿用五个场景分区，按主要主题映射深层代码；不改变场景几何或权限。普通 API 模块不加载完整分类数据，高级筛选按需加载选择器。
- 普通资料保存不修改原书；原文件写回仍走现有安全预览及补偿路径。新增字段作为元数据写入 EPUB/PDF，不替换阅读器实际 nav、正文或 PDF 书签。
- OpenAPI 与生成客户端已同步；现有书单、阅读、知识图谱、私有阅读数据及管理入口保留。
