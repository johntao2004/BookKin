# 藏书库一级导航布局打磨

根据 `/library` 的浏览器批注，检查桌面导航触发项的真实布局，修正下拉按钮与普通链接的样式差异。二级栏目、路由、权限和站点开关保持原逻辑。

## 布局审查

| Before | After | Why |
| --- | --- | --- |
| 下拉项行高 14px，其他链接 19.6px | 全部使用同一导航排版，行高 19.6px | 文字基线与视觉高度一致 |
| 下拉项内边距 0/10px，链接内边距 8/16px | 全部统一为 8/12px | 栏目间距有相同节奏 |
| 使用 16px 文字符号作为箭头 | 使用 12px 矢量下箭头并居中，展开时翻转 | 避免字形下沉和字体差异 |
| 下拉触发项沿用操作按钮表面，选中线覆盖文字与箭头 | 使用透明导航表面，选中线只跟随文字 | 一级栏目层级一致，减少按钮感 |

字体、间距、圆角、颜色与焦点均复用现有 Token；未新增设计 Token。保留 44px 触控高度和可见键盘焦点，未增加导航动画。

- 下拉展开、Escape 收起和方向下键重新展开正常；控制台未发现 error/warn。
