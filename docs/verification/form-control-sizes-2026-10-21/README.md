# 表单尺寸统一验证

> 历史验证：用户随后要求保留按钮大小，并将表单缩小至 40px。当前结果见 [输入控件匹配按钮尺寸](../compact-controls-2026-10-21/README.md)。

日期：2026-10-21。范围：共享输入框、密码框、搜索框、数字输入框和单选下拉框，以及页面内的尺寸覆盖。

- 使用现有 `layout.touchTarget`，单行控件外高统一为 44px；字号 16px，水平内边距 14px。
- 多行文本框保留行数和自动高度；密码/前后缀输入框的内部 input 不再重复增加高度和内边距。
- 清理初始化、顶栏搜索、虚拟书库搜索、分类和书单筛选的局部尺寸设置。宽度继续由响应式布局决定。

## 验证结果

- `pnpm lint && pnpm typecheck && pnpm test && pnpm build` 通过，140 个测试文件、600 项测试通过。构建保留现有的大包体提示；测试环境有 jsdom CSS/canvas 能力提示，无测试失败。
- 实际预览 `http://127.0.0.1:4176/library?advanced=1`：1440px 和 390px 视口内格式、排序、关键词、分类均为 44px，无页面横向溢出；手机下拉菜单能打开，控制台错误列表为空。
- 实际登录页：用户名及密码框外部均为 44px；密码内部 input 为 42px，位于 44px 的含边框容器内。
- 独立内存演示预览：设置字体上传表单、账户创建弹窗、AI 设置的数字及密码框均为 44px。390px 账户弹窗的三个控件同宽 310px，无页面横向溢出。只打开/取消表单，没有创建账户或提交设置。
- 书单编辑说明框保留四行编辑空间（约 122px），单行名称和可见性选择仍为 44px；输入多行文本后取消，未保存演示数据。
- API 健康检查为 UP。本次无后端代码修改，未提交、推送或部署。
