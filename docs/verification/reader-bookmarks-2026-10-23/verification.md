# 书籍与文章目录书签验收

日期：2026-10-23（Asia/Shanghai）

## 实现

- 共用阅读器按当前可见 EPUB CFI 或 PDF 原页/虚拟分页判断书签；可保存多处，移除当前处不会删除其他位置。
- EPUB/文章目录标题解析为原始文档 CFI 边界，章节旁显示可点击的书签图标。点击图标跳到保存位置，重复点击同一目标也会再次定位。
- PDF 读取原文件 outline；没有 outline 时，在同一目录抽屉直接列出带原页与分页的书签。
- PDF 在打开后响应新跳转目标，跨原页时保留目标分页，避免旧正文布局提前截断 offset。
- 文章书签保存使用既有独立阅读状态与 revision；删除保存失败时恢复书签并保留错误反馈。
- 保留按用户隔离、文章与书籍存储隔离及现有权限。没有修改数据库、NAS 原文件或后端代码。

## 持久化与隐私

真实 API 使用本地已有 ADMIN/MEMBER 验收账号：书籍两处书签在新登录会话中恢复；管理员看不到成员的测试书签；移除一处保留另一处；文章两处书签在新会话中恢复，文章状态不混入书籍批注。只清理本轮新增记录及临时文章，未删除既有记录。布尔结果见 `api-results.json`，不包含账号凭据。
