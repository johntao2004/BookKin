# 邮件配置与密码找回验证（2026-09-08）

## 功能入口

- 主人：`/settings#mail`，配置 SMTP、TLS/STARTTLS、发件邮箱、站点地址；保存后可发送测试邮件。
- 所有登录用户：`/settings#recovery-email`，凭当前密码申请邮箱验证；确认链接后才绑定。
- 登录页：`/forgot-password` 申请重置，邮件指向 `/recover#reset=...`；绑定指向 `/recover#bind=...`。
- 临时密码账户需先完成首次改密，才能进入设置。公开找回流程允许临时密码状态访问。
