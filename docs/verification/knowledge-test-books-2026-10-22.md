# 知识图谱功能测试素材与结果（2026-10-22）

## 本地测试素材

用户要求生成测试用书，并明确授权由助手直接生成图谱素材，以测试功能。新增四本原创 EPUB，每本三章、不同内嵌封面，已通过现有上传、元数据校对、确认入库流程进入本地书库，原有 126 本书保留，当前共 130 本。

| 书名 | 核心测试概念 |
| --- | --- |
| 图谱测试01·生态系统与碳循环 | 光合作用、碳循环、生物多样性 |
| 图谱测试02·森林修复与生态监测 | 光合作用、碳循环、生物多样性、样方调查 |
| 图谱测试03·河流生态与水质观察 | 生物多样性、富营养化、溶解氧、光合作用 |

生成目录：`.local/knowledge-test-books/`。书籍和知识点清单分别位于 `manifest.json`、`knowledge-fixtures.json`。

## 数据来源与边界

当前未启用可用 AI 平台，真实“开始分析”接口返回 AI_UNAVAILABLE。按照用户后续授权，助手直接编写并逐条核实测试知识点，通过仅允许连接本地数据库的测试脚本写入四本书对应的 book_knowledge。没有调用外部 AI，也没有修改或绕过正式分析接口。

测试记录 provider_id 为 `local-test-assistant-authored-v1`。状态 READY 代表此批功能测试素材就绪，不证明外部 AI 提取成功。每条知识点都有 EPUB 中连续存在的原文摘录和真实章节路径，绑定正式入库文件的 SHA-256。未直接插入书籍或阅读数据；不修改现有文件、权限或 AI 配置。浏览器实测阅读器会正常产生当前账户的真实阅读记录。

脚本：

```sh
python3 scripts/create-knowledge-test-books.py
# 先通过正常上传和校对流程入库
python3 scripts/seed-knowledge-test-data.py          # 验证素材，默认不写数据库
python3 scripts/seed-knowledge-test-data.py --apply  # 仅连接 loopback 本地开发数据库
```

生成脚本不覆盖内容不同的 EPUB。导入脚本以精确书名和文件哈希定位，仅写这四本；拒绝覆盖其他分析或进行中的任务；事务提交，重复运行不新增记录。

## 验证结果

- 4 个 EPUB ZIP 完整性、mimetype 首项且不压缩、XML、三章 spine、封面和唯一文件哈希检查通过。
- 14 条原文证据长度与连续匹配检查通过，9 个不同概念、14 条去重书内共现关联。
- 第二次运行生成器未改变 EPUB；第二次运行导入脚本插入 0 条，现有四条记录保持不变。
- 非本地数据库地址被脚本拒绝。
- 本地数据库查询：4 本 READY，每本采样/总章数 3/3，共 14 条知识点。
- 实际浏览器图谱显示两组独立网络；点击“生物多样性”显示测试书 01、02、03 及各自原文证据。
- 搜索“图谱测试04”只显示线装、纸张酸化、温湿度监测三个节点；缩放与重置可操作。
- 最终图谱浏览器控制台 error 列表为空。
- `git diff --check` 通过。
- 本轮只新增素材生成/本地注入脚本和报告，没有改动前后端应用代码，因此没有重复运行全量前端或 Maven 检查。
