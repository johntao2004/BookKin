# 输入控件匹配现有按钮尺寸

用户最新要求：保留按钮大小，将其他表单控件缩小到相同高度。本记录取代之前的 44px 表单尺寸方案。

## 修改

- 普通按钮主题和样式不变。单行输入、密码、搜索、数字输入和单选下拉框改用现有 `layout.controlHeight`（40px）。
- 保留统一的 16px 字号、14px 水平内边距，以及多行文本框的行数和自动高度。
- 移除字体上传表单内独立的 44px 高度覆盖，表单与按钮使用共享默认尺寸。
- 高级筛选的分类标签改用共享 `InputLabel`，修正与关键词标签行高不同引起的约 2px 错位。

## 浏览器验证

在实际预览 `http://127.0.0.1:4176` 验证，未使用内存演示模式，未提交任何设置。

- 1440px 藏书页：格式、排序和高级筛选按钮均为 40px，顶部和底部坐标完全一致；关键词输入框与分类下拉框也为 40px 且上下边缘完全对齐。
- 390px 藏书页：单行表单与普通操作按钮均为 40px，无页面横向溢出。
- 阅读字体设置：名称与类型选择同高且对齐，许可说明输入框与上传按钮同高且对齐，四项均为 40px。
- AI 设置：数字输入、普通输入、密码外部容器和下拉框均为 40px；控制台错误列表为空。
- 专用图标按钮维持原有尺寸，例如书籍卡片菜单按钮为 36px。
