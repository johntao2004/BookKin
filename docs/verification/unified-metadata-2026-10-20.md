# 元数据编辑页面统一验收

普通书籍编辑入口改为 `/library/books/:bookId/edit`，上传校对沿用 `/library/uploads/:uploadId`。两个路由均渲染 `MetadataEditPage`，共用页面标题、返回操作与 `MetadataEditorForm`。原 `MetadataDialog` 已移除，上传页面独立布局也已移除。

共用部分包括封面栏、封面裁剪、字段顺序、双列表单、公开展示、简介与响应式断点。普通书籍保留 Thema 分类、恢复封面和受控写回确认；上传保留草稿、补全、入库、取消等流程操作。未改动原文件安全、指纹与幂等流程。

保留普通元数据修改的即时缓存更新与同步返回。将通知调用放在应用级 FeedbackProvider 中，确保离开编辑页后后台持久化失败仍能显示回滚提示。
