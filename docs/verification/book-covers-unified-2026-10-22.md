# 全局书籍封面视觉统一

用户明确选择“统一铺满：卡片图片等宽等高，边缘适度裁切”。本次统一展示规则，不修改原始封面文件。

- 共享 BookCover 固定为 3:4 外框；图片宽高 100%、居中 object-fit cover，移除根据原图比例动态改变图片尺寸的逻辑。原图不会被拉伸，比例不同时裁切边缘。
- 圆角、背景、裁切和阴影由共享外框管理；低分辨率、横图、方图、长图、缺图和加载失败均保留相同外框。
- 普通目录、公开目录、书单中的书卡、禁书区书卡复用 BookCardPresentation；详情、概览、最近阅读、笔记、书单拼图、管理抽屉及元数据预览复用 BookCover。
- 清理回收站重复的背景/比例/阴影外框、笔记封面的局部强调色背景。保留回收站灰度状态及文章横向封面、自定义上传的 2:3 裁切流程。
