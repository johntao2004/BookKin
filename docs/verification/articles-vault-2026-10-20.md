# 文章收藏与个人禁书区验收（2026-10-20）

## 存储边界

- 普通书籍：原有 books/book_files、reading_positions、annotations、reading_time_daily 与 NAS 文件体系。
- 文章：articles/article_assets/article_asset_links/article_reading 独立表。正文为净化 HTML；图片在 `BOOKKIN_CONTENT_STORAGE_PATH/articles/<用户UUID>/<资源UUID>`。普通书籍接口不接收文章记录。
- 禁书区：personal_vault/vault_objects/vault_chunks 独立表。文件在 `BOOKKIN_CONTENT_STORAGE_PATH/vault/<用户UUID>/<存储UUID>`，正文、元信息、笔记、高亮、进度和计时均为密文。普通统计、AI 与知识图谱不读取这些表。
- 未配置 BOOKKIN_CONTENT_STORAGE_PATH 时使用 JVM 用户目录下 `.bookkin/content`。备份需要同时备份数据库与该目录；恢复密钥必须另行离线保管。

## API 与交互

- `/api/v1/articles`：文章列表、创建；`/{id}`：读取、编辑、删除。主人/管理员管理；公开文章可匿名读取；私有文章按归属与管理权限过滤。
- `/articles/fetch`：抓取公开 HTTPS 页面，预览后确认保存。图片规范化为 PNG；HTML/CSS 白名单；DNS 在实际连接解析阶段检查，重定向逐跳检查；不允许内网、环回、元数据或基准网段。
- `/articles/{id}/reading`：个人独立阅读状态，revision 乐观锁；冲突提示刷新，不静默覆盖其他页面。
- `/articles/{id}/knowledge`：通过现有 AI 网关提取具备原文证据的知识点。图谱合并 BOOK/ARTICLE 来源节点，相关文章回链到稳定段落；文章修改即失效旧知识点。
- `/vault/config`：版本化密钥信封。`/vault/objects`：密文清单；`/{id}/chunks/{index}`：不可覆盖的密文分块；`/{id}/state`：带 revision 的加密阅读状态。
- 二次密码使用 Argon2id（64 MiB、3 次、并行度 1）派生，AES-256-GCM 封装随机主密钥；独立 256 位恢复密钥。HKDF 为每个文件派生独立密钥，每块随机 nonce 并绑定文件 ID、块序号、块数和原始长度。
- 首版禁书区仅单独导入 EPUB/PDF；单文件最多 100 MiB、个人存储最多 2 GiB/1000 文件；不支持迁入、文章和云端分析。
- 主动锁定、闲置五分钟、刷新、离开页面或会话失效后需重新解锁。加密功能要求 HTTPS 或 localhost。浏览器内存和受控终端不属于绝对安全保证。

## 已验证

- 浏览器：文章手动输入、排版预览、确认保存、独立阅读页与个人笔记保存。
- 隔离验收账号：EPUB/PDF 加密导入、客户端解密阅读、加密笔记、高亮、错误密码拒绝与锁定隐藏。
- API/数据库：匿名专区访问 401；其他用户列表为空、分块访问 404、跨用户状态写入 409；成员创建普通文章 403，公开文章匿名读取 200。
- 验收账号普通阅读时间、批注、位置表均为零。全站普通阅读时间记录 9 条、3679 秒，批注 0 条，书籍 128 本，验收前后相同。
- 单元测试覆盖：认证加密解密、错误密钥、篡改、块调换、截断、nonce 随机性、文件密钥隔离、笔记来源绑定、危险 HTML、ZIP 路径逃逸、内网地址拒绝、正文定位和图片保留。
- 修复并复测 PDF Worker 转移 ArrayBuffer 后锁定清理报错：向 Worker 提供独立副本，并跳过已经分离的缓冲区。
