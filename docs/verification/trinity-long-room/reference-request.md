# Long Room reference access request — unsent draft

Subject: Access to Long Room architectural survey and reconstruction references

Hello,

I am developing a browser-based library experience inspired by the Old Library Long Room at Trinity College Dublin. I would like to replace estimated geometry with a carefully referenced reconstruction and clearly distinguish measured details from adaptations.

Your Long Room survey project describes a registered point cloud, an LOD300 Revit model and sectional/elevation drawings. Could you advise whether any of these can be made available for reference or licensed for this purpose, and whether permission must also be obtained from Trinity College Dublin?

The most useful material would be:

- Interior plans and sections showing gallery levels, bays, windows and the barrel vault.
- Both end elevations and the associated stair arrangements.
- Joinery profiles, gallery inscriptions and the layout of historical display furniture.
- Any available portrait-bust scans or multi-angle photographic references, including attribution and dated locations.

Please specify permitted use, attribution, modification and redistribution conditions, any fees, and whether derived geometry may be distributed in a public web application. Reference-only material would also be useful if model redistribution is unavailable.

The current application uses an intentionally enlarged architectural envelope at the user's request. That adaptation will be documented separately from the measured reference geometry.

Thank you.
