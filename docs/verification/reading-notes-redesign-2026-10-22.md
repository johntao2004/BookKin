# 阅读笔记改版验收 · 2026-10-22

## 页面与数据

- 顶部“阅读笔记”父入口进入 `/annotations/all` 总览，下拉仅保留“书籍”“文章”。总览混合当前用户的笔记、摘录和博文；两个分类页默认“阅读笔记”，另有“博文”Tab。
- 笔记直接显示摘录、正文、来源、日期和精确原文定位。提供来源、日期、文章标签筛选、搜索、表格查看和筛选结果 Markdown/CSV 导出。选中书籍后保留 Word/Excel 导出。
- 普通书籍批注、文章阅读状态、书籍博文和文章博文继续使用原有独立接口与存储，不读取禁书区。缓存包含用户身份。不同来源的同名记录使用来源类型、来源 ID、记录 ID 组合键。
- 旧全局批注接口最多返回 500 条；新展示通过分页读取有笔记的书籍，再以最多四个并发请求读取每本书完整记录，保证全文筛选/导出不因旧上限遗漏。博文继续沿用游标分页。
- 博文复用文章收藏卡片、来源封面和独立详情链接。分类页固定来源类型；从书籍详情、文章阅读器写作时绑定具体原文。无封面沿用统一占位。
- 共用 Markdown 编辑器支持全视口编写和预览。全屏隐藏元信息但保留来源、可见范围、修订号和草稿；不完整草稿保存时退出沉浸模式并显示可操作的校验信息。

## 浏览器实际验收

- 桌面 1118 × 865：父链接进入总览；键盘打开菜单仅显示两个分类。来源、排序、展示方式和导出控件与搜索输入底边对齐。
- 手机 390 × 844：单列卡片，无页面横向溢出；排序、展示方式并排。移动导航保留父入口和两个分类。分类默认“阅读笔记”，可切到“博文”再切回。
- 实际现有文章笔记可切换表格并导出 CSV。下载文件经读取确认包含完整摘录、笔记和编码后的精确原文位置。未新增或修改任何用户笔记、博文。
- 实际书籍详情写作显示“来源：书籍 · book”，没有重新选择原文的控件。文章写作也可绑定具体来源。
- 全屏编辑器桌面外框为 1280 × 720，手机外框为 390 × 844；文章草稿的 697 字符正文在全屏、预览、编辑往返后保持一致。预览包含标题、列表和表格。
- 在 390 × 568 小屏滚动验收：第二张卡片从 `data-note-visible=false` 进入视野后变为 `true`，透明度为 1；滚回后仍为 `true`，不重复播放。修复了异步数据刷新断开观察器后未重新观察待浮现卡片的问题。
- 减少动态效果通过 CSS 移除位移并保持正文可见，未更改用户的系统偏好。

## 检查

- 前端全量测试：155 文件、736 项通过。动效异步刷新回归测试单独通过；最后的笔记数据/动效聚焦检查共 2 文件、4 项通过。
- lint、typecheck、build 通过。测试仍输出 jsdom 伪元素、Canvas、部分 CSS 解析提示；构建有既有大分块提示，均未失败。
- 本轮无后端代码或数据库变更，未运行 Maven；无提交、推送或部署。
