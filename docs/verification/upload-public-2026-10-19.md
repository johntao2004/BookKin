# 上传与逐书公开展示调整（2026-10-19）

## 实现

- 新上传默认公开；完成解析、人工确认及正式入库后才进入公开首页，暂存稿不直接发布。
- 上传编辑页增加“公开展示”开关，默认开启；关闭后提交的书籍仍进入登录后的书库，但不进入公共书目。该选择随草稿 JSON 保存；刷新、在线补全、AI 再匹配均保留。
- 已有书籍的“编辑元信息”也提供同一开关，读取真实公开状态。书目编辑与可见性修改位于同一个 application service 数据库事务；旧客户端不传该字段时保持原状态。
- 公共展示以现有 display catalog membership 为唯一数据来源，不增加相互冲突的可见性列。撤下为幂等操作；成功上传的 commit 幂等重放不重新发布，避免覆盖后来选择的“不公开”。
- 取消独立展示管理页面入口，`/display-books`、`/settings/display-books` 和旧设置锚点跳转到藏书库；首页不再提供“管理首页书目”按钮。原有公共阅读访问检查保持生效。
- 藏书库概览可显示/隐藏，按用户在本地保存；隐藏后保留全部藏书、筛选、上传和排序。
- 上传弹窗支持点击、Enter/空格和拖入，移除副标题及内容上下边线、投放区框线。
- 上传编辑页隐藏字段来源标签、目标路径、文件名与指纹；格式、大小和页/字数置于封面下。来源及安全路径仍由后端保留。危险色取消上传按钮与补全、保存位于同一操作区。
