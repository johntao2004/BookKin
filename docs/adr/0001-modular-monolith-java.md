# ADR-0001：Java 模块化单体与双 Profile

- 状态：已采纳
- 日期：2026-08-20

## 决策

后端使用 Java 21、Spring Boot 4.1 的模块化单体。单一构建产物分别以 `api` 和 `worker` Profile 运行。

## 原因

NAS 家庭部署更看重可维护性和故障恢复，而非独立服务弹性。Java 的类型系统、成熟的安全/批处理/数据库生态和可控并发适合长时间扫描与文件事务；双 Profile 可隔离 HTTP 与 I/O 工作负载，又不引入分布式部署复杂度。

## 后果

模块边界必须通过包约束、测试和公开服务维护。若未来独立扩展 worker，现有数据库任务协议可作为拆分边界。
