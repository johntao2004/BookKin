# ADR-0002：NAS 文件操作采用持久化补偿事务

- 状态：已采纳
- 日期：2026-08-20

## 决策

文件系统与 PostgreSQL 无法共享 ACID 事务，因此使用持久化操作日志、显式阶段、幂等键、指纹前置条件和补偿动作。

## 不变量

1. 目标文件永不被静默覆盖。
2. 跨根目录移动在目标验证完成前保留源文件。
3. 元数据写回在替换前保留完整原版本。
4. 数据库记录只在文件阶段达到可证明状态后推进。
5. 重试同一幂等操作不会产生第二份副作用。

## 后果

用户会看到异步任务和可重试失败状态；换取 NAS 断连、进程终止和外部修改下的可恢复性。

## 当前实现说明（2026-09-06）

不变量中的“原版本”由 `.bookkin-staging/metadata` 下的事务内临时回滚文件实现；失败恢复，成功提交后删除。它不是可浏览的历史版本库。旧 `.bookkin-versions` 仅保留兼容清理，详见技术架构。
