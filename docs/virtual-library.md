# 虚拟书库

更新日期：2026-10-17。入口 `/virtual-library`，需要登录。网页继续使用 Three.js。直播建筑是一座原创的窄长厅，不再使用 2026-10-09 那版约 155 万三角的宽厅。

## 当前厅

内厅约 16 m 宽、40 m 长，单拱顶冠高 11.2 m，回廊在 4 m。南端是入口，默认镜头站在门内朝北看。两侧各八个凹室，走道约 3.4 m。走道上有三张阅读桌和桌灯。两座旋梯左右错开。北端一道原创铁栅，门洞可走，栅后是更暗的空架，没有阅读桌。滚动梯贴在部分书架靠走道的一面，只作造型和碰撞。

建筑三角面由 `scripts/hogwarts-library/build_narrow_hall.mjs` 生成，预算上限 40 万。当前导出远低于这个上限。贴图是脚本画的 512 像素木纹、石纹和一张灯与书的静物，没有人物。

- `library-manifest.json`：四个模块。只有 `entrance` 是核心和首屏
- `materials.gltf`：共享材质和外链 PNG
- `modules/*.glb`：未压缩的 glTF 二进制。不再使用「逐三角无损 Meshopt」
- `scene-config.json`：碰撞、楼梯路径、局部暖光

方向光阴影只盖入口附近，不再用一张 2048 的贴图罩住整厅。曝光约 0.82。三盏桌灯是 `#ffb15a`，距离约 5.4 m。

## 真实目录与交互

- 地面优先，南端入口开间优先。真书按分类落在这些书位上
- 每面六层 × 20 个地址。没有书的层保持空架，不放填充书或装饰书脊
- 保留 Thema 分类、真实书名和封面、选架、旋转查看、短点击阅读及返回原视角
- 分类按钮不铺在画面上，收在「搜索藏书」里
- 目标书架、楼梯和阅读返回位置会先确认对应模块
- W/A/S/D、拖动环顾、Shift/Ctrl 升降仍然可用

## 加载

首屏等待的是入口模块。相机看到的其他开间按现有队列每次最多两个继续加载，北端不在首屏集合里，也不在入口阴影范围内。这台环境里的帧时间和软件 WebGL 不能当成显卡验收。

## 许可

网格、栏杆、铁栅、桌子和贴图都是这次脚本里的原创几何和程序纹理。不用华纳、霍格沃茨校名、院徽、角色或游戏提取资源。概念图只在设计说明里，不进 `public`。

## 开发入口

- `VirtualLibraryExperience.tsx`：漫游、楼梯、搜索
- `hogwartsLibraryLayout.ts`：尺寸、镜头、书位节距
- `referenceLibrary.ts`：配置、碰撞、书位锚点、入口阴影
- `referenceLibraryStreaming.ts`：分块加载
- `scripts/hogwarts-library/build_narrow_hall.mjs`：重新导出

`build_library.py` 是已退役的宽厅脚本。不设置 `BOOKKIN_LEGACY_HALL=1` 时它会直接退出，避免覆盖现在的模块。更早的验证记录仍在 `docs/verification/`，描述的是退役的那一版。
