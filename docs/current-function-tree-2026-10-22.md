梳理日期：2026-10-22。以下保留本轮导航调整前的结构快照，包含当时尚未提交的修改；不代表线上版本。后续首页合并、导航收敛和设置重组已实施，最新结构与验收见 [导航合并验收记录](verification/navigation-consolidation-2026-10-22.md)。

阅读方式：`[页面]` 表示独立路由；`[分区]` 表示同一页面中的标签或内容区；`[弹窗/抽屉]` 不另算页面；`[场景]` 表示 3D 页面内的空间切换。下面按用户入口组织，缩进表达功能归属，不要求 URL 具有相同父子关系。

匿名时，主导航只保留“首页、书单”，仍可使用公开搜索和公开书籍阅读。登录后主导航最多显示 8 项；虚拟书库取决于站点功能开关。页面内的管理按钮继续按角色控制。

管理员可见设置中的用户管理、书库状态、阅读字体、AI 书目匹配四个一级分区；主人可见全部六个。当前是固定主人/管理员/成员角色，没有独立角色管理页面。主人可创建管理员或成员，管理员可创建成员；账户启停、临时密码和会话撤销还受目标用户角色及是否为本人限制。

## 2. 页面之间真正的关系

| 页面/分区 | 当前定位与边界 |
| --- | --- |
| 首页 | 实际是“公开书目浏览页”，登录后仍请求公开展示目录；没有藏书库的四卡阅读概览。 |
| 藏书库 | 登录后自己的可访问馆藏入口，结合阅读概览、书目浏览与管理员入库/管理操作。 |
| 书籍详情 | 藏书库点击封面进入；展示完整元数据，是书目的详情页。 |
| 书籍阅读器 | 独立阅读页面，被首页、书单、搜索、知识图谱、虚拟书库等入口复用。 |
| 文章阅读器 | 独立文章 URL，共用书籍阅读器界面；文章阅读记录独立。文章目前仍要求登录，即使编辑时标为公开，也不是匿名可访问的文章路由。 |
| 禁书区阅读 | 在 `/vault` 内切换，独立加密数据、二次密码及恢复流程；不是普通书籍阅读路由。 |
| 阅读笔记 | 当前汇总普通书库批注；文章和禁书区笔记分别留在各自阅读流程中，没有形成统一的跨内容笔记页。 |
| 知识图谱 | 跨书籍/文章按正文知识点关联，与人工分类、人工书单的组织依据不同。 |
| 虚拟书库 | 同一普通馆藏的 3D 浏览入口；两个房间是场景状态，不能计为两张独立管理页，也不能直接等同于 `/vault` 的加密业务。 |
| 设置 | 一个路由，六个一级分区；其中用户管理再嵌五个二级标签。每个标签不是独立路由页面。 |
| 个人信息 | 一个页面内同时放账户资料、找回邮箱和改密；改密另外保留独立流程页。 |

值得注意的入口差异：普通藏书库点击书卡进入书籍详情；首页、搜索和书单详情中的书卡默认直接进入阅读器，导致“同样点击封面”出现两种行为。

## 4. 从现状看，值得下一步讨论的合并点

以下是对现状的判断，不是已经执行的改版。

| 现状 | 为什么显得繁杂 | 后续可讨论方向 |
| --- | --- | --- |
| 首页 + 藏书库 | 两张顶级页面都以书卡、筛选、排序为主体；区别主要是公开范围、概览和管理操作。 | 统一藏书入口，按登录状态/公开范围展示；保留匿名和私人内容边界。 |
| 书库高级筛选 + 全站搜索 | 都能搜书，用户不易理解差异；全站搜索还搜笔记、书单、分类。 | 明确一个全站搜索入口，列表内保留局部筛选；评估是否仍需独立搜索页。 |
| 藏书库 + 书单详情 + 3D 书库 | 都在呈现同一批馆藏，但分别承担全量浏览、人工分组和空间浏览。 | 共用书籍卡片、详情与操作；评估 3D 是否降为藏书库视图入口。 |
| 分类 + 书单 + 知识图谱 | 都在组织书，但分类靠标签体系、书单靠人工收集、图谱靠正文知识关联。 | 分类已经内嵌；先明确三者用途，再决定是否降低某些入口层级。 |
| 用户管理下面的操作日志 | 实际展示 NAS 文件任务进度、阶段及结果，与“用户列表”不是同类事项。 | 考虑与书库状态、文件任务、回收站形成馆藏管理分组。 |
| 个人信息改密 + 独立改密页 | 同一表单有两个表现位置。 | 常规改密留在个人信息；独立页用于必须改密等特殊流程。 |
| 三类阅读和笔记 | 普通书、文章、禁书区分开保存，但用户缺少统一的笔记发现入口。 | 先统一界面与入口语言；是否聚合普通书与文章笔记另行决定，禁书区锁定与数据边界必须保留。 |
| 旧路由 + 旧 Page 文件 | 代码中的页面数量高于用户实际能打开的页面数量。 | 清理不可达旧实现、统一命名，同时保留必要的旧链接兼容。 |

当前最需要优先理清的是：**首页与藏书库的关系、用户管理与馆藏管理的分组、普通书与文章的阅读/笔记入口，以及缺少可见入口的回收站。**

## 5. 核查依据与范围

- 路由与访问边界：`apps/web/src/App.tsx`。
- 主导航、顶栏搜索、头像菜单：`apps/web/src/components/AppShell.tsx`。
- 设置与嵌套标签：`SettingsPage.tsx`、`UserManagementPage.tsx`、各实际嵌入面板。
- 各业务页及其真实引用组件：`apps/web/src/pages/`、`components/`、`features/vault/`。
- 本次为当前源码结构核查，未启动服务、未运行测试或构建、未验证浏览器及线上状态；未提交、推送或部署。
