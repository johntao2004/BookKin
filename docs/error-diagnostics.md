# 页面错误与请求排查

页面级错误使用统一的独立错误页面，显示实际 HTTP 状态、稳定错误代码、原因及服务端提供的请求标识。401/403 保留登录或返回入口，404 说明链接不存在；参数错误和服务器错误保留具体状态，不互相替代。表单校验和不阻断页面的局部操作错误仍在原位置处理。

权限服务故障每五秒自动重试，重试中保留上次错误及请求标识，成功取得新权限后恢复原页面。恢复不能绕过当前权限检查。

服务端为请求生成 UUID，并放入 `X-Request-ID` 响应头。统一异常响应的 `traceId` 与该响应头相同，日志的 `[trace=...]` 也使用同一标识。管理员可复制页面请求标识，在部署服务的日志中精确检索；本地 API 日志位于 `.local/logs/api.log`。

预期业务错误保留业务代码，参数校验使用 `VALIDATION_FAILED`，未处理的服务器异常使用 `INTERNAL_ERROR`。未知异常的完整堆栈只记录到服务端日志，不返回路径、密钥或原始异常文本。验证失败日志不记录表单值或请求查询参数。

网络中断、超时和浏览器渲染失败没有服务器 HTTP 响应时，不伪造 500。此时显示连接或客户端错误代码；没有收到服务端请求标识时也不伪造标识。

主要接入点包括认证/权限边界、未知页面、页面渲染边界、藏书和书目列表/详情、文章列表/阅读及文集列表/详情。辅助信息加载或编辑操作失败不应丢弃已打开的内容或输入。
