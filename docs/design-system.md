# BookKin 设计规范

## 1. 设计原则

BookKin 的视觉语言是“安静的私人藏书室”：暖色纸张、深墨文字、少量珊瑚强调和深色阅读状态面板。它借鉴编辑出版物的节奏，但不复制任何现有产品的品牌、组件造型或页面布局。

原则按优先级排序：

1. 内容先于装饰：书封、书名、作者、进度和操作风险必须清楚。
2. 危险操作可预期：NAS 写操作先预览，明确源、目标、冲突、空间和可恢复性。
3. 安静而不寡淡：大面积暖白，深色块只承载进行中或高信息密度区域。
4. 跨设备一致：桌面用于管理，平板与手机用于浏览和阅读，信息层级不改变。
5. 可访问：键盘可达、焦点可见、44px 触控目标、正文对比度至少 4.5:1。

## 2. Token 与实现约束

`design/tokens.json` 是所有数值的唯一真源。脚本生成：

- `apps/web/src/theme/generated-tokens.ts`：Ant Design 主题与 BookKin UI 适配层输入；
- `apps/web/src/theme/generated-tokens.css`：浏览器 CSS Variables；
- Figma 变量命名和代码语法映射。

禁止在业务组件中直接写品牌色、间距、圆角和阴影。例外仅限图像内像素值、第三方阅读器内部样式和协议要求。

核心语义色：

| Token | 值 | 用途 |
|---|---:|---|
| `color.canvas` | `#FAF7F0` | 应用底色 |
| `color.surface` | `#FFFDF8` | 卡片、输入 |
| `color.textPrimary` | `#191816` | 标题、主要正文 |
| `color.primary` | `#C56F4E` | 主操作、进度强调 |
| `color.focus` | `#39867A` | 键盘焦点与同步状态 |
| `color.surfaceDark` | `#191816` | 正在阅读、阅读器工具栏 |

## 3. 字体与排版

- 展示字体：`Noto Serif SC`，回退到思源宋体、系统宋体；用于品牌、页标题、书名。
- UI/正文字体：`Inter` + `Noto Sans SC`/苹方；用于导航、表单、表格、说明。
- 等宽字体：`JetBrains Mono`；只用于路径、指纹、任务编号和日志。
- 大标题用常规字重，不用粗黑；正文 16px、行高 1.65；管理表格最小 14px。
- 长路径采用中间省略，悬停/聚焦显示完整值，并提供复制按钮。

## 4. 布局与响应式

- 1440px：最大内容宽 1360px；画廊 6–8 列；详情以侧栏或双栏出现。
- 1024px：画廊 4–5 列；管理表格保留关键列，其余进入详情抽屉。
- 390px：单列主任务；画廊 2 列；筛选使用底部抽屉；危险操作使用全屏对话框。
- 顶栏桌面高 72px；内容区水平边距为 24–48px，手机为 16px。
- 间距只使用 4px 基准 Token；卡片默认 12px 圆角，输入和按钮为 8px。

## 5. 核心组件映射

| BookKin 组件 | Ant Design 基础 | 关键约束 |
|---|---|---|
| `BookKinButton` | Ant `Button` | 高度至少 44px；主按钮珊瑚色 |
| `BookKinField` | Ant `Input` | 标签常驻；错误信息不改变表单宽度 |
| `BookCard` | Ant `Card` | 封面比例 2:3；标题最多两行 |
| `StatusChip` | Ant `Tag` | 文字与颜色双编码状态 |
| `OperationPreviewDialog` | Ant `Modal` | 先摘要后完整变更清单；危险项不可折叠隐藏 |
| `DataTable` | HTML table / Ant table contract | 游标分页；批量选择跨页不默认保留 |
| `SideNavigation` | Ant `Drawer` | 管理区与阅读区分组 |
| `ReaderToolbar` | BookKin shell + Ant controls | 深色、可自动隐藏、键盘可达 |

AntV 图表通过 `apps/web/src/charts/antv.ts` 统一创建，后续统计功能应复用该入口并继续使用本文件中的语义 Token。

## 6. 文件管理交互

每次重命名、移动、移入回收站、恢复和写回都遵循四步：

1. 选择：显示受影响数量、格式和根目录。
2. 预览：服务端返回规范化后的源路径、目标路径、空间、指纹和冲突。
3. 确认：用户明确确认；永久清理要求再次输入书名或数量。
4. 执行：进度抽屉显示计划、运行、成功、失败或回滚；可复制任务 ID。

冲突不用模糊的 toast 表达。必须在变更行内显示：冲突类型、已有目标、建议修正和重新预览入口。任何情况下都不提供“覆盖已有文件”。

回收站默认按到期时间排序，显示原路径、删除者、大小、到期日与校验状态。恢复前再次预览；目标已存在时只允许修改恢复路径或取消。

## 7. 状态、反馈与文案

- 成功：说明实际结果，例如“已移入回收站，可在 30 天内恢复”。
- 失败：说明未发生什么，例如“目标校验失败，源文件保持不变”。
- 运行：展示当前阶段，不用虚假百分比；跨根移动可显示已复制字节数。
- 空状态：给出下一步，如“添加书库根目录”或“调整筛选条件”。
- 不使用恐吓式文案；永久清理清楚说明不可恢复。

## 8. 阅读器

- EPUB 阅读宽度默认 680–760px，支持亮色、纸色、深色主题与字号/行距调节。
- PDF 默认进入逐页懒解析的阅读模式，把可提取文字按当前主题、字号和舒适行宽重排；工具栏可切换“阅读模式 / 原版”。没有文字层的图片页直接在正文宽度内展示页面图像并标记“未进行 OCR”，无需切回深色原版界面；原版仍保留页码、缩放和精确版面。
- 选择正文后显示四项紧凑工具条：高亮、高亮并写笔记、下划线、加粗；前三类一触即存，写笔记进入二级输入面板。工具条同时提供浅亮的黄色、绿色、粉色、蓝色和橙色五种荧光笔预设。
- 批注样式、荧光笔颜色、原文锚点与笔记内容一并保存；“高亮并写笔记”的原文必须在正文和笔记列表中保持同色高亮。工具条不得遮挡当前选区，390px 视口保持至少 44px 触控目标。
- 笔记首页以书籍卡片作为一级分类，封面、书名、作者、批注总数和笔记数形成固定信息层级；点击卡片进入单书时间流。单书页保留正文中的高亮、下划线和加粗外观，Word/Excel 导出与“回到书中”操作置于标题区，手机端改为纵向全宽按钮。
- 390px 上工具栏分层，首层只保留返回、目录、进度和设置。

## 9. Figma 页面结构

`BookKin · 电子图书馆 V1`：Cover、Getting Started、Foundations、Components、Auth、Library、Reader、File Management、Responsive、Utilities。变量名使用斜杠层级，并设置 Web code syntax 指向生成的 CSS Variable。
